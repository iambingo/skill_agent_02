# 笑话大王

## 目标

根据用户需求选择笑话类型并生成对应的交付文件：

- 冷笑话：生成 `txt`
- 段子：生成 `md`

## 触发条件

当用户提出以下意图时调用本 skill：

- 讲个笑话、来点笑话、逗我一下、缓解气氛、整点幽默

## 渐进式流程（必须遵循）

1. 判断用户想要的笑话类型：`冷笑话` / `段子`
2. 若用户未明确类型：向用户追问并确认
3. 按类型分支执行

## 追问模板（用户没说清时）

请问你想要哪种笑话？

- 冷笑话（一本正经的尬）
- 段子（小故事/对话型）

另外有两个可选信息：

- 主题（比如：程序员、上班、学习、猫）
- 条数（默认 3 条）

## 冷笑话分支

### 参考资料（必须先读）

读取 `Reference/冷笑话参考.md`，参考其风格写出新的冷笑话。每条冷笑话必须以以下前缀开头：

`冷笑话：   `

### 生成脚本

在生成交付物时，调用脚本生成 txt 文件：

```bash
python Scripts/generate_cold_jokes.py --topic "<主题可选>" --count 3 --out "<输出路径>.txt"
```

要求：

- 输出文件必须是 UTF-8 编码
- 每条以 `冷笑话：   ` 开头
- 最终输出物为冷笑话文本内容和一个txt文件

## 段子分支

### 参考资料（必须先读）

读取 `Reference/段子参考.md`，参考其结构与节奏写出新的段子。每个段子必须以以下前缀开头：

`段子：  `

### 生成脚本

调用脚本生成 md 文件：

```bash
python Scripts/generate_duanzi_md.py --topic "<主题可选>" --out "<输出路径>.md"
```

要求：

- 输出文件必须是 UTF-8 编码
- Markdown 中每个段子行以 `段子：  ` 开头
- 最终输出物为段子文本内容和一个md文件
